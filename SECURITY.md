# Security

This repository contains interest-rate infrastructure for the Lido Lend product.

Before submitting a report, check the [current Lido Immunefi scope](https://immunefi.com/bug-bounty/lido/scope/). The program covers listed deployed and released assets, not the latest repository or development branches. Send findings about undeployed repository code to [security@lido.fi](mailto:security@lido.fi), the contact published in Lido's [security.txt](https://lido.fi/.well-known/security.txt).

Do not disclose a vulnerability publicly before it has been triaged and remediated.
